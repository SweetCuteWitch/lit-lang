# Кнопки «Словарь» и «Уроки» под прогрессом

Дата: 2026-11-19 · Статус: утверждено пользователем

## Зачем
Пользователь хочет из «📊 Прогресс» быстро посмотреть все свои слова (перевод и формы) и перечитать
теорию пройденного урока: сначала увидеть список тем с названиями, потом выбрать номер.

## Цели
- Под сообщением «📊 Прогресс» — inline-кнопки [📖 Словарь] [📚 Уроки].
- **Словарь** → в тему 📖 Словарь: все слова пользователя, сгруппированные по урокам
  (`📖 Урок N: <название>`), строка на слово: `<b>лемма</b> — перевод (род) · формы через запятую`.
  Без примеров. Сообщения ≤ 4000 символов; длиннее — несколько сообщений, разрыв только между строками.
- **Уроки** → в тему 📚 Уроки: список пройденных уроков `N. <название>` и строка
  «Напишите номер урока, чтобы прочитать его ещё раз.» Пройденный = у урока есть выданная порция.
- После этого бот 10 минут ждёт номер. Сообщение, состоящее только из целого числа, в это время —
  выбор урока (даже во время занятия; ответы в заданиях — слова, не числа). После выбора ожидание снимается.
- Номер пройденного урока → в тему 📚 Уроки вся теория урока: его выданные порции по `seq`, тем же
  форматом, что при первой выдаче (`📚 Урок N: <название> · часть k` + теория).
- Номер непройденного/несуществующего → «Такого урока пока нет. Доступны: 1–4.» (список номеров),
  ожидание остаётся.
- Команды-дубли: `/vocab`, `/lessons`.

## Не-цели
- Поиск по словарю, листание страницами, выбор урока кнопками (вариант А отклонён пользователем).
- Изменение карточек слов при выдаче порции и самого прогресса.

## Подходы
- **А. Кнопки с номерами уроков** — без ввода и без конфликта с ответами. Отклонён: пользователь хочет
  сначала список с названиями и ввод номера.
- **Б. Ввод номера после списка (выбран)** — ожидание номера хранится в настройке `awaitingLesson`
  (`{ until: ISO }`), проверяется до разбора ответа на задание.

## Решения Claude
- Окно ожидания — 10 минут; только «чистое» целое число (`/^\d{1,3}$/`).
- Словарь — все слова, а не только выученные; слова урока — в порядке добавления.
- Без тем Telegram всё приходит в общий чат (как сейчас работает `send`).
